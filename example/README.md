# cute_kid_fonts example

Gallery of every role × palette, a Czech keyboard of `KidKeyLabel`s, the
diacritics sheet, a 50-row list for jank checks and a Flame scene
(`KidBubbleComponent` + `KidTextPaint`).

```bash
flutter run -d macos   # or android / ios / chrome
```

`screenshots/` are copies of the package's golden images
(`flutter test --update-goldens` in the package root, then copy).
